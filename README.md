# Amazfit Active 2 Square Watchfaces

Coleção de watchfaces personalizadas para o **Amazfit Active 2 Square**.

## Objetivo

Desenvolver diferentes estilos de mostradores, priorizando:

- boa legibilidade durante o uso diário;
- visual limpo e personalizável;
- acesso rápido a informações importantes;
- compatibilidade com o modelo Amazfit Active 2 Square.

## Estrutura do projeto

Cada watchface deve ficar em sua própria pasta:

```text
watchfaces/
├── nome-da-watchface-01/
├── nome-da-watchface-02/
└── nome-da-watchface-03/
```

Uma pasta de watchface pode conter:

```text
nome-da-watchface/
├── README.md       # descrição e instruções específicas
├── assets/         # imagens, ícones e fontes
├── src/            # arquivos-fonte
└── build/          # arquivos gerados para instalação
```

## Informações exibidas

Dependendo do design, as watchfaces poderão incluir:

- hora;
- data e dia da semana;
- bateria;
- passos;
- frequência cardíaca;
- distância;
- calorias;
- clima;
- alarmes ou outros indicadores.

## Diretrizes de design

- Manter contraste suficiente entre texto, ícones e fundo.
- Evitar excesso de informações na tela principal.
- Testar a leitura em ambientes claros e escuros.
- Usar elementos alinhados e consistentes entre as watchfaces.
- Confirmar resolução, formato e limitações do Amazfit Active 2 Square antes da exportação final.
